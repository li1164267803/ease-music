## Why

C6b 的前两片（`add-plugin-discovery-charts`、`add-plugin-discovery-albums-artists`，均已归档）让用户能在插件里浏览榜单、歌单、专辑与艺人作品，但曲目只能**逐首**加入曲库。一张几十上百首的榜单或歌单，逐首点加是不现实的；而用户在其他平台维护多年的歌单——协议里 `importMusicSheet` / `importMusicItem` 对应的「粘贴链接导入」——至今没有入口。这是 C6b 第三片，也是路线图上 C6 的最后一块。

前两片把它推迟的原因是一个前置决策：**外部歌单与本项目歌单体系如何映射**。本 change 先把这个决策定下来（见 `design.md` 决策 1），再在它之上做批量入库与链接导入。

## What Changes

- **映射规则（前置决策）**：导入是一次**快照**。导入的产物是一个普通的本地歌单——与用户手建的歌单完全同一种东西，不记录来源、不跟随外部更新、不依赖任何插件存在。要「更新」就再导一次：曲目按插件主键去重，重复导入到同一歌单只追加新增的曲目。
- **整个列表批量入库（Android 独占）**：榜单、歌单、专辑、艺人单曲四种候选曲目页增加「全部加入歌单」入口。系统先取完该列表的全部页，再把曲目一并入库并放进歌单——新建歌单（默认以来源标题命名，可改）或追加到既有歌单，保持来源顺序。已在曲库的曲目不重复入库，但同样进歌单。
- **导入外部歌单链接**：用户选定一个实现了 `importMusicSheet` 的插件，粘贴链接或 ID；插件自述的粘贴提示（`hints`）显示在输入框下方。解析出的曲目以候选曲目列表呈现，可逐首加入，也可整个列表加入歌单。
- **导入单曲链接**：同上，走 `importMusicItem`，结果是一条候选曲目。
- **插件对链接的三种回答分别处理**：识别并返回曲目、识别但没有曲目、不识别该链接。三者在界面上说清，不混成「插件出错」。
- **插件未实现导入方法不视为错误**：加载期判定，未实现的插件不出现在导入入口的可选插件里。
- **iOS 侧沿用编译期裁剪**：全部界面在发现层子树之内，门面不改。曲库侧新增的批量入库函数不引用插件模块。

### 非目标

- **跟随外部更新的「订阅型」歌单**：与映射决策相悖，理由见 `design.md` 决策 1；不是推迟，是明确不做。
- **导入时把曲目一并缓存离线**：正交，用户导入后可在歌单里逐首或（未来）整单下载，属于 C2 的能力扩展。
- **候选曲目直接试听**：独立 change，前两片同样排除。
- **跨插件猜测链接归属**（不选插件、粘贴后由系统逐个试）：两个样本插件都接受纯数字 ID，同一串数字无法判断属于谁；由用户指定插件是唯一无歧义的做法（`design.md` 决策 5）。
- **导入进度的逐首展示与中途取消**：取页阶段有进度文字，入库阶段是一次事务，几百首在毫秒级完成，没有需要取消的窗口。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `plugin-discovery`：新增四条要求——导入的歌单是普通本地歌单（映射规则）、整个列表批量入库、导入外部歌单链接、导入单曲链接。候选曲目、故障隔离、iOS 上不存在等既有要求不改措辞，自然覆盖新增路径。`playlist` 与 `music-library` 的既有要求（去重、歌单内顺序、重复加入不产生重复条目）正是本 change 依赖的行为，不需要改动。

## Impact

- **`src/plugins/protocol.ts` 与 `host/loader.ts`**：`PluginMeta` 增加两个导入方法的判定与插件自述的粘贴提示。
- **`src/plugins/discovery.ts`**：新增取完整个列表、导入歌单链接、导入单曲链接三个函数；后两者的形状校验要区分「不识别」与「畸形」。
- **`src/plugins/manager.ts`**：新增按导入能力筛选插件的函数；发现首页的可用性判断把导入能力算进去。
- **`src/domain/repository/track-repository.ts` 与 `src/library/import.ts`**：曲库侧增加**一次事务内的批量入库**，以及「候选曲目批量入库并放进歌单」的动作。这两处在核心层，不引用插件模块。
- **`src/plugins/screens` 与 `src/plugins/ui`**：候选曲目页加入口；新增导入页 `/plugin-discovery/import`；新增「加入歌单」目标选择弹层（新建或既有歌单、进度、结果）；发现首页加导入入口；管理页能力描述补「导入」。
- **`src/plugins/api.ts` 与两份门面**：契约不改。
- **依赖**：无新增。`check:ios-strip` 与 ESLint 清单登记新增屏幕。
- **文档**：`README.md` 与 `openspec/PRODUCT.md` 路线图更新 C6b-3 状态；`docs/architecture.md` 插件一节补导入方法与批量入库路径。
