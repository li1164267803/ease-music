## MODIFIED Requirements

### Requirement: 远程 URL 来源

系统 SHALL 支持用户手动添加一个可直接访问的音频 URL 作为曲目。

#### Scenario: 添加远程 URL 曲目

- **WHEN** 用户输入一个有效的音频直链并确认
- **THEN** 该曲目被加入曲库并可以播放

#### Scenario: 拒绝无效输入

- **WHEN** 用户输入的内容不是合法的 URL
- **THEN** 系统 SHALL 在加入曲库前提示输入无效，不创建曲目记录

#### Scenario: 远程地址失效

- **WHEN** 播放一首远程 URL 曲目，但该地址返回错误或无法连接
- **THEN** 系统 SHALL 向用户报告播放失败及失败原因，曲目保留在曲库中不被自动删除；报告的原因 MUST 能让用户区分「地址返回了错误」（并给出服务端返回的状态码）与「无法连接到该地址」，MUST NOT 只呈现播放引擎的原始英文错误信息

#### Scenario: 地址可访问但音频无法解码

- **WHEN** 播放一首远程 URL 曲目，该地址可以正常访问，但返回的内容无法作为音频播放
- **THEN** 系统 SHALL 向用户报告该音频无法解码，曲目保留在曲库中不被自动删除
